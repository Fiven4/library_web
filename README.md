# Библиотека: клиент библиотечной системы на Flutter Web

Практические работы 2 и 3. Каталог из пяти сущностей со списками, поиском, фильтрами, сортировкой, пагинацией, универсальными формами создания и редактирования, валидацией, связями и сохранением данных в браузере.

Web-приложение на Flutter для управления каталогом библиотечной системы из пяти связанных сущностей: книги (`Book`), авторы (`Author`), жанры (`Genre`), издательства (`Publisher`) и читатели (`Reader`) с вложенными читательскими билетами (`LibraryCard`).

Все параметры отбора (поиск, фильтры, сортировка, пагинация) синхронизируются с адресной строкой браузера: ссылку на любое отфильтрованное состояние можно скопировать и открыть в новой вкладке. Данные хранятся в `localStorage` браузера (через `shared_preferences`) с версионированием и автоматической миграцией формата (`v1` → `v2`).

Разработка и запуск выполнены в Android Studio (устройство «Chrome (web)»).

## Сущности и связи

В системе реализовано 5 основных моделей, полностью соответствующих контракту учебного REST API:

| Сущность | Тип связи | Описание связей в системе |
|---|---|---|
| **Book** (Книга) | N:M с `Author`<br>N:M с `Genre`<br>N:1 с `Publisher` | Множественный выбор авторов и жанров (`MultiSpec`), выпадающий список издательства (`DropdownSpec`). Каскадная фильтрация авторов по выбранному издательству. |
| **Author** (Автор) | M:N с `Book` | В детальной карточке автора выводится список всех его книг. Защита от удаления при наличии связанных книг. |
| **Genre** (Жанр) | M:N с `Book` | В детальной карточке отображаются относящиеся книги. Контроль уникальности наименования. |
| **Publisher** (Издательство) | 1:N с `Book` | Карточка издательства показывает каталог его книг. Защита от физического удаления с указанием числа блокирующих книг. |
| **Reader** (Читатель) | 1:1 с `LibraryCard` | Читательский билет оформлен вложенной группой полей (`GroupSpec`): номер билета, даты выдачи и окончания срока действия. |

## Что реализовано

- **Чистая многослойная архитектура:**
  - `models` — DTO-модели (`Book`, `Author`, `Genre`, `Publisher`, `Reader`, `LibraryCard`) и объекты запросов (`*Query`) с сериализацией `toJson`/`fromJson`, устойчивой к `null` и отсутствующим полям.
  - `repositories` — абстрактные интерфейсы и общая параметризованная реализация `LocalRepository<T, Q>` с пятью специализированными репозиториями.
  - `state` — управление состоянием на `provider` (`ChangeNotifier`). Виджеты изолированы от репозиториев и работают через нотифаеры (`EntityListNotifier`, `EntityDetailNotifier`, `EntityFormNotifier`).
  - `screens` и `widgets` — переиспользуемые компоненты `EntityListView<T, Q>`, `EntityTable<T>`, карточки и общая форма `EntityFormView`.
- **URL как единственное состояние списков (ПР2):**
  - Маршрутизация на `go_router` (`MaterialApp.router`), адреса без `#` (`usePathUrlStrategy()`).
  - Все условия (поиск, фильтры, сортировка, номер страницы, размер страницы, флаг показа удалённых) хранятся в query-параметрах адреса. Состояние полностью восстанавливается при открытии ссылки или обновлении страницы.
- **Поиск, фильтрация, сортировка и пагинация:**
  - Живой поиск с задержкой 400 мс (`Debouncer`).
  - Фильтры по выпадающим спискам, диапазонам годов, статусу билета (`active` / `expired`).
  - Сортировка по клику на заголовки таблицы (включая обратный порядок).
  - Пагинация с выбором размера страницы (10, 25 или 50 элементов).
- **Универсальный декларативный движок форм (ПР3):**
  - Маршруты `/<entity>/new` и `/<entity>/:id/edit` используют единый виджет формы.
  - Поля описываются спецификациями: `TextSpec`, `DateSpec`, `DropdownSpec`, `MultiSpec`, `GroupSpec`.
  - Справочники для выпадающих списков и множественного выбора загружаются динамически из репозиториев (добавленный жанр мгновенно появляется в форме книги).
- **Многоуровневая валидация (`lib/core/validators.dart`):**
  - Обязательность, минимальная и максимальная длина, числовые диапазоны.
  - Форматы: ISBN (с дефисами или без), Email, телефон, номер билета, даты.
  - Перекрёстные проверки: доступных экземпляров не может быть больше общего количества; срок действия билета должен быть позже даты выдачи.
  - Асинхронный контроль уникальности: ISBN книги, Email и номер билета читателя, наименования жанров и издательств.
- **Ссылочная целостность и каскады:**
  - Защита от удаления: издательство, автор или жанр, на которые ссылаются книги, невозможно удалить. Диалог показывает точное число связанных книг. При групповом удалении связанные сущности пропускаются с отчётом.
  - Каскадное сужение: при выборе издательства список авторов автоматически фильтруется по тем, кто уже публиковался в этом издательстве (с возможностью переключения на полный список).
- **Безопасность данных и `PopScope`:**
  - Отслеживание изменений формы. При попытке покинуть несохранённую форму (через кнопку интерфейса или кнопку «Назад» браузера) отображается диалог подтверждения.
- **Хранилище с версионированием (`JsonStore`):**
  - Персистентность через `shared_preferences` (`localStorage` браузера).
  - Ключи с префиксом версии: `books_v2`, `authors_v2` и др.
  - Автоматическая миграция со старого формата (`*_v1`), безопасное восстановление начальных сид-данных (`seed_data.dart`) при повреждении с показом понятного уведомления пользователю.
- **Адаптивный дизайн:**
  - Ширина < 600 px: карточки вместо таблицы, нижняя панель навигации, адаптированные поля форм.
  - Ширина ≥ 600 px: полноразмерная таблица, боковое меню навигации (`NavigationRail`).
- **Тестирование и качество:**
  - 9 файлов тестов в каталоге `test/` (модели, репозитории, валидаторы, хранилище, форма, экраны и навигация).
  - Чистый анализ `flutter analyze` без предупреждений и ошибок.

> [!NOTE]
> **Исправление ошибки в `deleteMany` (ПР2):**
> В исходной лабораторной заготовке проверка записывалась как `!b[i].isDeleted` (ошибка компиляции Dart: у `Book` нет оператора индексатора `[]`, а переменная `i` использовалась некорректно). Проверка была исправлена на `!b.isDeleted`. Логика вынесена в обобщённый метод `LocalRepository.deleteMany` и покрыта тестами.

## Маршруты

### Пути навигации

| Маршрут | Описание |
|---|---|
| `/` | Перенаправление на `/books` |
| `/books` | Каталог книг (таблица / карточки, фильтры, поиск, сортировка, пагинация) |
| `/books/new` | Форма добавления новой книги |
| `/books/:id` | Детальная карточка книги |
| `/books/:id/edit` | Форма редактирования книги |
| `/authors` | Список авторов |
| `/authors/new`, `/authors/:id`, `/authors/:id/edit` | Создание, просмотр и редактирование автора |
| `/genres` | Список жанров |
| `/genres/new`, `/genres/:id`, `/genres/:id/edit` | Создание, просмотр и редактирование жанра |
| `/publishers` | Список издательств |
| `/publishers/new`, `/publishers/:id`, `/publishers/:id/edit` | Создание, просмотр и редактирование издательства |
| `/readers` | Список читателей |
| `/readers/new`, `/readers/:id`, `/readers/:id/edit` | Создание, просмотр и редактирование читателя (с читательским билетом) |
| Любой другой адрес | Страница 404 (`NotFoundScreen`) с кнопкой возврата |

### Параметры адреса (Query Parameters)

Все параметры отбора в списках сериализуются в адресную строку через `Uri(path:, queryParameters:)`:

| Параметр | Описание | Пример значения | По умолчанию |
|---|---|---|---|
| `search` | Поисковая подстрока (с дебаунсом) | `search=война` | `""` (пусто) |
| `genreId` | Идентификатор выбранного жанра | `genreId=2` | не задан |
| `publisherId` | Идентификатор выбранного издательства | `publisherId=1` | не задан |
| `authorId` | Идентификатор выбранного автора | `authorId=3` | не задан |
| `yearFrom`, `yearTo` | Диапазон года издания книги | `yearFrom=1960&yearTo=2000` | не задан |
| `country` | Фильтр авторов по стране | `country=Россия` | не задан |
| `city` | Фильтр издательств по городу | `city=Москва` | не задан |
| `card` | Статус билета читателя (`active` или `expired`) | `card=active` | не задан |
| `sort` | Поле и направление сортировки | `sort=year,desc` | первое поле, по возрастанию |
| `page` | Номер страницы (1-based) | `page=2` | `1` |
| `size` | Размер страницы (10, 25 или 50) | `size=25` | `10` |
| `includeDeleted` | Показывать логически удалённые записи | `includeDeleted=true` | `false` |
